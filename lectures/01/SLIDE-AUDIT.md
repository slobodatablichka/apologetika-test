# Тема 1 — фактическая привязка слайдов (рабочая проверка)

**Статус:** прежняя смысловая сборка не прошла проверку. Исправление опубликовано на /lectures/01/. Это не означает окончательной экспертизы всех фотографий.

## Что установлено по просмотру контактных листов

Фотографии №1–21 образуют вводный блок об апологетике: её предмет, направления, аргументация и литература. С №22 начинается другой блок: «Наука и религия», определения культуры и религии, далее понятие и практика науки. Поэтому нельзя механически назначать изображения по сходству отдельных слов.

| Фото (номер в исходном ZIP) | Реальное содержание на слайде | Использование |
|---|---|---|
| 1 | Апологетика: предмет и определение | Вводное определение дисциплины |
| 3 | Четыре направления апологетики | Изложение направлений |
| 22 | «Наука и религия»: титульный кадр | Введение в основной блок |
| 25 | Определения культуры | Культура и классификации определений |
| 28 | Схематическое деление культуры | Материальная, социальная, духовная |
| 31 | Римский мыслитель Цицерон | Этимологические трактовки religio |
| 34 | Определение религии в православном богословии | Религия; затем устное сопоставление с иными традициями |
| 35 | Определение науки | Понятие науки |
| 44 | Научная деятельность и её особенности | Человеческая сторона научной работы; этический вывод в речи |
| 49–50 | Продолжение естественнонаучного блока | Только временный экран для переходов, не иллюстрация веры и разума |
| 55 | Продолжение блока о науке | Технический фон для озвучивания тем без подходящего слайда, не их иллюстрация |

## Неустранённые содержательные ограничения

1. Слайды №49–55 **не подтверждены** как прямые иллюстрации веры и разума, деизма, пантеизма или атеистической критики. Презентация не должна выдавать их за таковые.
2. Требуется полный поштучный просмотр фотографий, чтобы определить, есть ли эти смыслы в других частях 234-слайдового корпуса.
3. Дикторский текст в этих местах — материал по исходной лекции, произносимый без нового слайда. Это допустимо как переход, но слишком большие фрагменты на чужом изображении ухудшают лекцию.
4. Окончательная мужская аудиозапись и синхронизация по её длительности не готовы; текущий браузерный голос — только испытание.

**Условие приёмки:** для каждого экранного перехода записать фактическое содержание фото, конкретный смысл исходного Word, текст объяснения и отметку «прямая иллюстрация / связующий речевой переход». Не проводить финальную озвучку до завершения сопоставления.
