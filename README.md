# Апологетика — система тематических тестов

Статический учебный сайт GitHub Pages: https://slobodatablichka.github.io/apologetika-test/

## Назначение
Проект — фрагмент образовательной программы по готовым лекциям преподавателя апологетики.

- Оригинальный преподавательский тест на **48 вопросов** на главной странице сохраняется отдельно.
- Новый приоритет — **тематические тесты по каждой доступной оригинальной лекции**, с произвольным адекватным числом вариантов, одним или несколькими правильными ответами, объяснениями и предварительной оценкой сложности 1–5.
- По мере накопления вопросов — **стратифицированная псевдослучайная сборка вариантов примерно по 50 вопросов** с сопоставимой сложностью и охватом.
- Фотографии преподавателя из репозитория `diafilm` допускаются как необязательные пояснения к разбору. Озвучка отменена.

## Репозиторий
`slobodatablichka/apologetika-test`, ветка `main`. Сайт публикуется через GitHub Pages. `index.html` содержит исходный тест; тематические модули разрабатываются независимо.

## Единый производственный регламент

Работа по следующим лекциям ведётся по [TEST-PRODUCTION.md](TEST-PRODUCTION.md), редакция 2.0: исходный DOCX → авторские разделы и укрупнённые аналитические блоки → смысловая карта draw.io → содержательные вопросы с полными ключами и объяснениями → экспертная оценка сложности 1–5 → банк JSON и действующая страница теста. Ориентир 30–40 вопросов, не более 50; числа блоков и вопросов не фиксируются.

Первая разработка: [карта](maps/tema-01-smyslovaya-karta.drawio), [банк 36 вопросов](tests/lecture-01-bank.json), [страница теста](tests/lecture-01.html). Содержательная приёмка первой редакции ещё не завершена.
