# Апологетика — тренировочный тест

Статический сайт для GitHub Pages.

Содержимое:
- `index.html` — весь тест и интерфейс;
- `.nojekyll` — отключает обработку Jekyll.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий, например `apologetika-test`.
2. Загрузите в корень репозитория `index.html` и `.nojekyll`.
3. Откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`, Folder: `/(root)`.
6. Нажмите `Save`.

После публикации GitHub покажет адрес сайта.
