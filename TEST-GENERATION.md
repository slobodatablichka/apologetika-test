# TEST-GENERATION — формирование сбалансированных вариантов

**Редакция 1.0 · 20 октября 2026 · утверждена общая архитектура; численные параметры предварительны.**

## Назначение
После накопления достаточного числа проверенных вопросов объединять тематические банки в **псевдослучайные варианты примерно по 50 вопросов**, сопоставимые по **среднему уровню сложности** и охвату материала курса.

## Правила отбора
1. Отбирать исключительно проверенные вопросы с полными ключами, пояснениями, лекцией-источником и предварительной оценкой сложности 1–5.
2. Задать для выпуска одинаковые условия: целевое число вопросов, тематические доли и распределение по уровням сложности. **Конкретные доли пока не утверждены.**
3. Выполнять **стратифицированный псевдослучайный отбор** внутри сочетаний «тема × уровень сложности»; учитывать достаточность банка и предотвращать дубли близких вопросов в одном варианте.
4. Контролировать одновременно: число вопросов; распределение по темам; распределение по сложности; средневзвешенную сложность; отсутствие повторов и чрезмерной концентрации одинаковых понятий.
5. Фиксировать генератор, его версию, условия выборки и seed, позволяющий воспроизвести конкретный вариант. При невозможности выполнить ограничения — **сообщать об этом, не подменять недостающие вопросы случайными неподходящими**.
6. После проведения тестов анализировать реальную трудность и качество вопросов; уточнять первоначальные экспертные оценки, не изменяя историю уже созданных вариантов.

## Расчёт сложности
Для варианта из N вопросов со сложностями dᵢ: **средняя сложность = сумма dᵢ / N**. Равенство среднего недостаточно: также контролируется распределение уровней 1–5 и тематическая структура.

## Ответы, результаты и разбор
- Вопрос может иметь один или несколько правильных вариантов, а количество предложенных вариантов не фиксировано.
- Полный балл за вопрос даётся при точном совпадении всех выбранных вариантов с исчерпывающим ключом. Иной способ начисления частичных баллов требует отдельного утверждения.
- В разборе ошибок выделяются правильные, пропущенные и ошибочно выбранные варианты и даётся содержательное объяснение.
- Ссылки на оригинальные слайды из `diafilm` могут быть присоединены к разбору **позднее**; наличие слайда не является условием выбора вопроса.

## Неутверждённые параметры
Точная длина варианта (ориентир — 50), квоты тем и уровней, допуск по среднему, политика повторов между различными вариантами, порядок обновления экспертных оценок — утвердить после появления достаточно большого проверенного банка. **Пример распределения 5/10/20/10/5 не является нормой.**

## Идентификаторы вопросов и связь с картами

Варианты отбираются из банка по неизменным ID `Q-L.S.E-NN`, привязанным к элементам `L.S.E` оригинальной лекции. ID нужны для обнаружения дублей, тематического покрытия и воспроизводимой генерации. Карты `.drawio` из `maps/` могут помогать проверять охват смыслов, но **не выступают источником ключей или входом генератора вместо структурированного банка**. Стандарт и правила draw.io: `START.md`, `TEST-PRODUCTION.md`.
